# Pictogrammes de l’essai 6

Quatre SVG vectoriels originaux, dessinés pour l’interface : journal, aide, menu, horloge. Aucune image distante ou police d’icônes requise. Les petits signes de la fiche sont dessinés dans `hud_details.gd`.

Toutes ces décorations ignorent les événements tactiles. Les couleurs d’état lisent uniquement les textes déjà autorisés dans la fiche, sans accéder au moteur ni aux informations ennemies cachées.
