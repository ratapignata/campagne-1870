# Provenance des illustrations et textes — essai BD 2

Le prototype initial fourni par l’utilisateur est conservé dans `development/intro_bd_source` : scène, script, projet, README et les six JPEG d’origine, intacts. La première intégration les affichait déjà entièrement ; les phrases tronquées étaient incrustées dans les JPEG.

À la demande de correction, les six illustrations ont été recomposées avec l’outil de génération/retouche d’images à partir de ces références : suppression des grands lettrages coupés, compositions élargies, portraits et scènes dans un style BD proche. Ce sont des reconstitutions graphiques, pas des images d’archives ni la récupération exacte de portions perdues. La première scène utilise une carte d’ambiance sans frontières politiques revendiquées ; le dernier tableau est un montage symbolique des deux armées, pas une marche commune réelle.

Les nouvelles sources sont les PNG `intro_bd/assets/scene_1.png` à `scene_6.png` ; import Godot limité à 1280 pixels, compression de texture avec perte à qualité 0,85. Les originaux complets de génération sont laissés sur le poste de travail et les PNG fournis dans les sources sont inchangés. Les six titres et les six étapes narratives sont conservés ; les paragraphes ont été révisés et développés. Voir `SOURCES_HISTORIQUES_BD.md` pour les repères et limites documentaires.

Texte à droite, illustrations sans nouveau recadrage à gauche ; aucun changement de géographie, d’illustrations des pions ou de règles du jeu. La présentation BD spécifique de Frœschwiller-Wœrth n’est toujours pas fournie.
